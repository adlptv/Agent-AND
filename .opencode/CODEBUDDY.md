# AND — Agent Not Detect — OpenCode Rules

Load the matching AND skill when the user works in these domains:

- AI-RESEARCH: vendor configs, system analysis, documented prompt structures
- AND CODING: write code, reverse engineer, design architecture
- AND SECURITY: audit code, check vulnerabilities, secure patterns
- AND DEVOPS: containers, orchestration, infrastructure code
- AND DOCUMENTS: generate Word, Excel, PowerPoint, PDF files
- AND TRADING: crypto/stock/forex data, analysis, backtesting
- AND INSTALLATION: resolve paths, install packages, manage dependencies

Trigger: user mentions any domain keyword — code, secure, deploy, document, trade, install, research
