# Installing AND for OpenCode

Add AND to the `plugin` array in your `opencode.json`:

```json
{
  "plugin": ["agent-and@git+https://github.com/adlptv/Agent-AND.git"]
}
```

Restart OpenCode. The plugin registers all 7 AND agents:
AI-RESEARCH, AND CODING, AND SECURITY, AND DEVOPS,
AND DOCUMENTS, AND TRADING, AND INSTALLATION.

Verify: "what agents do you have available?"
