# PINTAR — Coding & Reverse Engineering

## Full-Stack Patterns
- **BE**: Node.js (Express, Fastify), Python (FastAPI, Django), Go (Chi, Gin), Rust (Actix)
- **FE**: React, Next.js, Vue, Svelte, HTMX, Alpine.js
- **DB**: PostgreSQL, MongoDB, Redis, SQLite, ClickHouse
- **API**: REST, GraphQL, gRPC, WebSocket, SSE

- **Binary**: Ghidra, IDA Pro, x64dbg, radare2, objdump, strings
- **Protocol**: Wireshark, tcpdump, mitmproxy, Burp Suite
- **Web**: Chrome DevTools, source maps, obfuscated JS deobfuscation
- **Mobile**: APKTool, jadx, Frida, objection
- **.NET**: dnSpy, ILSpy, de4dot

- Microservices, Monolith, Modular Monolith, Serverless
