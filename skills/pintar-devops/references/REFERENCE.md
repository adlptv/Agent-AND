# PINTAR DevOps Reference

## Containers
- Docker: multi-stage builds, distroless images, Docker Compose
- Kubernetes: Pods, Deployments, Services, Ingress, Helm, ConfigMaps
- Security: non-root, read-only fs, seccomp profiles

## Infrastructure as Code
- Terraform: providers, modules, state management, workspaces
- Pulumi: TypeScript/Python infrastructure
- Ansible: playbooks, roles, vault
- CloudFormation, ARM templates, Bicep

## CI/CD
- GitHub Actions: workflows, matrix builds, reusable workflows
- GitLab CI: stages, artifacts, environments
- ArgoCD: GitOps, application sets
- Flux: Helm releases, image automation

## Cloud
- AWS: EC2, S3, Lambda, RDS, EKS, IAM, CloudFront
- GCP: Compute Engine, Cloud Storage, Cloud Run, GKE, BigQuery
- Azure: VMs, Blob Storage, Functions, AKS, Entra ID
- Platforms: Vercel, Netlify, Cloudflare Workers, Fly.io, Railway

## Monitoring
- Metrics: Prometheus + Grafana, Datadog
- Logs: ELK, Loki, Splunk
- Traces: Jaeger, OpenTelemetry, Zipkin
- Alerts: Alertmanager, PagerDuty
